# Step 2: 문제 생성

## 목표

3개의 문제를 생성한다 (객관식 2개, 빈칸채우기 1개).

---

## 진행 순서

### 1. 문제 관리 페이지 접속

**URL:** `/questions`

좌측 메뉴에서 "문제 관리"를 클릭하거나 직접 URL로 접속한다.

![문제 관리 페이지](./screenshots/03-question-list.png)

### 2. 문제 1 생성: 객관식 (인수분해)

**새 문제** 버튼 클릭 후 다음 정보를 입력한다.

| 필드 | 값 |
|------|-----|
| 문제명 | 다항식 x^2 + 7x + 12를 인수분해하면? |
| 과목 | 수학 |
| 유형 | 객관식 |
| 난이도 | 보통 |
| 배점 | 10 |

**보기 입력:**
- 보기 1: (x+3)(x+4)
- 보기 2: (x+2)(x+6)
- 보기 3: (x+1)(x+12)
- 보기 4: (x-3)(x-4)

**정답:** 1번 (첫 번째 보기)

![문제 1 생성](./screenshots/04-question-create-1.png)

### 3. 문제 2 생성: 객관식 (집합)

**새 문제** 버튼 클릭 후 다음 정보를 입력한다.

| 필드 | 값 |
|------|-----|
| 문제명 | 집합 A = {1, 2, 3, 4, 5}의 부분집합의 개수는? |
| 과목 | 수학 |
| 유형 | 객관식 |
| 난이도 | 보통 |
| 배점 | 10 |

**보기 입력:**
- 보기 1: 16
- 보기 2: 25
- 보기 3: 32
- 보기 4: 64

**정답:** 3번 (세 번째 보기)

![문제 2 생성](./screenshots/05-question-create-2.png)

### 4. 문제 3 생성: 빈칸채우기 (등차수열)

**새 문제** 버튼 클릭 후 다음 정보를 입력한다.

| 필드 | 값 |
|------|-----|
| 문제명 | 등차수열 2, 5, 8, 11, ...의 제10항은? |
| 과목 | 수학 |
| 유형 | 빈칸채우기 |
| 난이도 | 쉬움 |
| 배점 | 10 |

**정답:** 29

![문제 3 생성](./screenshots/06-question-create-3.png)

---

## 예상 결과

- 문제 목록에 3개의 문제가 표시됨
- 각 문제의 과목, 유형, 난이도, 배점 확인 가능
