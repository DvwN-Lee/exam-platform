# Step 3: 시험지 생성

## 목표

앞서 생성한 3개의 문제를 포함하는 시험지를 생성한다.

---

## 진행 순서

### 1. 시험지 관리 페이지 접속

**URL:** `/testpapers`

좌측 메뉴에서 "시험지 관리"를 클릭하거나 직접 URL로 접속한다.

### 2. 새 시험지 생성

**시험지 생성** 버튼을 클릭한다.

### 3. 시험지 정보 입력 및 문제 선택

| 필드 | 값 |
|------|-----|
| 시험지 제목 | 수학 기초 테스트 |
| 과목 | 수학 |

생성된 문제 목록에서 다음 3개의 문제를 선택한다:

1. 등차수열 2, 5, 8, 11, ...의 제10항은? (10점) - 순서 1
2. 집합 A = {1, 2, 3, 4, 5}의 부분집합의 개수는? (10점) - 순서 2
3. 다항식 x^2 + 7x + 12를 인수분해하면? (10점) - 순서 3

![시험지 생성](./screenshots/03-testpaper-create.png)

### 4. 저장

**시험지 생성** 버튼을 클릭하여 시험지를 생성한다.

---

## 예상 결과

- 시험지 제목: 수학 기초 테스트
- 총 문제 수: 3문제
- 총점: 30점
