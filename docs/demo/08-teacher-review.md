# Step 8: 교사 결과 확인

## 목표

교사 계정으로 로그인하여 학생들의 시험 결과를 확인한다.

---

## 진행 순서

### 1. 로그아웃

우측 상단의 프로필 메뉴에서 **로그아웃**을 클릭한다.

### 2. 교사 계정으로 로그인

**URL:** `/login`

| 필드 | 값 |
|------|-----|
| 아이디 | demoteacher01 |
| Password | demo1234! |

### 3. 시험 관리 페이지 접속

**URL:** `/examinations`

좌측 메뉴에서 "시험 관리"를 클릭한다.

![시험 목록](./screenshots/08-teacher-exam-list.png)

### 4. 시험 결과 확인

"2026년 1학기 수학 시험"의 **상세** 버튼을 클릭한다.

### 5. 학생별 결과 확인

응시한 학생 목록과 통계가 표시된다.

**시험 통계:**

| 항목 | 값 |
|------|-----|
| 평균 점수 | 20점 |
| 최고점 | 20점 |
| 최저점 | 20점 |
| 합격률 | 100% |
| 제출률 | 100% (1/1명) |

**학생별 결과:**

| 학생명 | 학번 | 점수 | 제출시간 | 상태 |
|--------|------|------|----------|------|
| 학생1 | 20240001 | 20점 | 2월 7일 오후 06:45 | 합격 |

![학생별 결과](./screenshots/08-teacher-exam-results.png)

### 6. 교사 Dashboard 확인

교사 Dashboard에서 전체 현황을 확인한다.

| 항목 | 값 |
|------|-----|
| 생성한 문제 | 3개 |
| 시험지 수 | 1개 |
| 총 응시자 | 1명 |
| 평균 점수 | 20.0 |

![교사 Dashboard](./screenshots/08-teacher-dashboard-after.png)
