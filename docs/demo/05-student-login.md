# Step 5: 학생 로그인

## 목표

교사 계정에서 로그아웃 후 학생 계정으로 로그인한다.

---

## 진행 순서

### 1. 로그아웃

우측 상단의 프로필 메뉴에서 **로그아웃**을 클릭한다.

### 2. 로그인 페이지 접속

**URL:** `/login`

![로그인 페이지](./screenshots/05-student-login.png)

### 3. 계정 정보 입력

| 필드 | 값 |
|------|-----|
| Username | demo_student1 |
| Password | demo1234! |

### 4. 로그인 버튼 클릭

로그인 버튼을 클릭하여 인증을 완료한다.

---

## 예상 결과

- 로그인 성공 후 학생 Dashboard로 이동
- 상단 네비게이션에 학생 메뉴 표시:
  - 시험 목록
  - 내 결과

![학생 Dashboard](./screenshots/05-student-dashboard.png)
