# Step 7: 학생 결과 확인

## 목표

제출한 시험의 결과를 확인한다.

---

## 진행 순서

### 1. 결과 페이지 접속

시험 제출 후 자동으로 결과 페이지로 이동하거나, "성적 조회" 메뉴를 통해 접속한다.

**URL:** `/exams/:id/result`

![결과 페이지](./screenshots/07-exam-result.png)

### 2. 점수 확인

| 항목 | 값 |
|------|-----|
| 총점 | 30점 |
| 획득 점수 | 20점 |
| 정답률 | 66.7% |
| 통과 여부 | 합격 |
| 총 문제 수 | 3개 |
| 정답 수 | 2개 |

### 3. 문제별 결과 확인

| 문제 | 내 답안 | 정답 | 결과 | 배점 |
|------|---------|------|------|------|
| 문제 1 (등차수열) | 30 | 29 | 오답 | 10점 |
| 문제 2 (집합) | 32 | 32 | 정답 | 10점 |
| 문제 3 (인수분해) | (x+3)(x+4) | (x+3)(x+4) | 정답 | 10점 |

---

## 예상 결과

- 20/30점
- 정답률 66.7%
- 정답 2개, 오답 1개 (등차수열 문제)
