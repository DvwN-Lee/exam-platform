# Exam Platform Demo 시나리오

## 개요

Exam Platform의 전체 기능을 시연하는 데모 시나리오이다. 교사가 문제와 시험을 생성하고, 학생이 시험에 응시한 후 결과를 확인하는 전체 흐름을 다룬다.

---

## 데모 흐름

```
[교사] 로그인 → 문제 생성 → 시험지 생성 → 시험 생성
        ↓
[학생] 로그인 → 시험 목록 확인 → 시험 응시 → 결과 확인
        ↓
[교사] 학생 결과 확인
```

## 사전 준비

### 1. 데모 계정 생성

Production 환경에서 데모 데이터를 생성한다.

```bash
# Backend Pod에 접속하여 데모 데이터 생성
kubectl exec -it deployment/exam-prod-exam-platform-backend \
  -n exam-platform-prod -- python manage.py seed_demo_data
```

**생성되는 데이터:**
- 교사 계정: demo_teacher / demo1234!
- 학생 계정: demo_student1~5 / demo1234!
- 과목: 수학, 영어, 과학, 국어, 사회
- 샘플 문제 8개

### 2. 접속 환경

- **URL:** https://exam-platform.me
- **지원 브라우저:** Chrome, Firefox, Safari (최신 버전)

## 데모 문제 세트

이 데모에서 생성할 문제 목록이다. 생성 순서와 시험지 내 배치 순서는 다를 수 있다.

### 객관식 (수학 - 인수분해)

| 항목 | 값 |
|------|-----|
| 문제 제목 | 다항식 x^2 + 7x + 12를 인수분해하면? |
| 과목 | 수학 |
| 문제 유형 | 객관식 |
| 난이도 | 보통 |
| 배점 | 10점 |
| 선택지 | (1) (x+3)(x+4), (2) (x+2)(x+6), (3) (x+1)(x+12), (4) (x-3)(x-4) |
| 정답 | (1) |

### 객관식 (수학 - 집합)

| 항목 | 값 |
|------|-----|
| 문제 제목 | 집합 A = {1, 2, 3, 4, 5}의 부분집합의 개수는? |
| 과목 | 수학 |
| 문제 유형 | 객관식 |
| 난이도 | 보통 |
| 배점 | 10점 |
| 선택지 | (1) 16, (2) 25, (3) 32, (4) 64 |
| 정답 | (3) |

### 빈칸채우기 (수학 - 등차수열)

| 항목 | 값 |
|------|-----|
| 문제 제목 | 등차수열 2, 5, 8, 11, ...의 제10항은? |
| 과목 | 수학 |
| 문제 유형 | 빈칸채우기 |
| 난이도 | 쉬움 |
| 배점 | 10점 |
| 정답 | 29 |
